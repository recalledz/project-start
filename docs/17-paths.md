19 – Paths & Attribute Affinities

Each disciple chooses one Path after completing Foundation. Paths define their elemental focus, archetype, and unlock unique abilities. A new disciple starts with one of the Starter Paths and can switch when Foundation completes.


---

19.0 Starter Paths

Path	Element	Archetype	Focus

Path of the Ember	Fire (火)	Mage	Combat Spells, Qi generation, culture speed
Path of the Emerald	Wood (木)	Ranger	Travel speed, gathering, stat boosts
Path of the Azure Saint	Water (水)	Healer	Healing, crowd control, weather control
Path of the Searing Shield	Fire (火)	Tank	Defense, resilience, frontline combat



---

19.2 Attribute Affinities

Each Path grants affinity scores (1–5) to base attributes, influencing training speed and bonuses.

Path	DEX	END	STR	INT	CHA

Path of the Ember	2	1	1	5	2
Path of the Emerald Ranger	5	3	3	3	3
Path of the Azure Saint	2	1	1	5	3
Path of the Searing Shield	2	5	5	2	3
Path of the Ruby Red Mage	3	2	2	4	3
Path of the Thunder Thief	5	2	2	3	4
Path of the Verdant Druid	3	3	1	4	4
Path of the Gale Bard	4	2	1	4	5
Path of the Frost Monk	3	4	4	2	1
Path of the Sapphire Summoner	1	1	1	5	3
Path of the Glacial Ninja	5	2	2	4	2
Path of the Ivory White Mage	1	2	1	5	4
Path of the Storm Dragoon	3	4	5	2	2
Path of the Luminous White Mage	1	2	1	5	4
Path of the Obsidian Dark Knight	2	5	5	1	2


Affinity scores scale attribute XP gain by (affinity × base rate).
