# 02 – Sect Recruitment

**Sunday, July 13, 2025 • 6:54 PM**

- Start with 3 disciples; maximum grows with housing buildings.
- Base attributes = 3 each; +6 points randomly distributed among
  - Dexterity (DEX)
  - Endurance (END)
  - Charisma (CHA)
  - Intelligence (INT)
  - Strength (STR)
- New disciples recruited via the **Calling** spell.
