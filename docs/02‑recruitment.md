# 02 – Sect Recruitment

**Sunday, July 13, 2025 • 6:54 PM**

### Attributes

- Start with 3 disciples; maximum grows with housing buildings.
- Base attributes = 3 each; +6 points randomly distributed among
  - Dexterity (DEX)
  - Endurance (END)
  - Charisma (CHA)
  - Intelligence (INT)
  - Strength (STR)
- New disciples recruited via the **Calling** spell.

### Starting skill levels

- (random number from 14.6-32) * 1.25 * (learning speed / 100)
- LearningSpeed = 0.5 + 0.15 × Intelligence
- example: intelligence 5/ learning speed = 125%
- 20 * 1.25 * 125/100 = 31.25
- all liked skill recieve 1.4 skill level and 3 skill levels for loved ones.
- Then, the remaining are randomly ditributed to other skills as follows:
- if random skill is loved, then add 3 skill levels
- if random skill is liked, then add 1.4
- otherwise, add 1 skill level.
- maximium of 10 skill levels can be obtained this way.
