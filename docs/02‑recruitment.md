# 02 – Sect Recruitment

**Sunday, July 13, 2025 • 6:54 PM**

### Attributes

- Start with 3 disciples; maximum grows with housing buildings.
- Base attributes = 3 each; +6 points randomly distributed among
  - Dexterity (DEX)
  - Endurance (END)
  - Charisma (CHA)
  - Intelligence (INT)
  - Strength (STR)
- New disciples recruited via the **Calling** spell.

### Starting Skill Levels

- `(random number from 14.6–32) × 1.25 × (learning speed / 100)`
- `LearningSpeed = 0.5 + 0.15 × Intelligence`
- Example with Intelligence 5 → learning speed 125%
- `20 × 1.25 × 125/100 = 31.25`
- All liked skills receive 1.4 levels and loved skills receive 3 levels.
- The remaining total is randomly distributed to other skills:
  - If the random skill is loved, add 3 levels.
  - If the random skill is liked, add 1.4 levels.
  - Otherwise, add 1 level.
- A maximum of 10 levels can be gained from this distribution.
