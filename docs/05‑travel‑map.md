# 05 – Travelling & Map

**Friday, July 11, 2025 • 11:51 PM**

- **Exploration** unlocks via **Foreseers** research.
- Assign disciples to regions; time spent yields **Discovery Points**.
- Two starting regions; initial location: **Scrubland Trees** (distance 0.5).
- **Stamina Costs**:
  - Travel: 25 STA per distance unit (one‑way).
  - Exploring: 0.25 STA per second.
- **Travel Speed** = (1 + 0.1 × artifact_skill_level) × (1 + speed_bonus).
- Shrine levels reduce travel STA by 4% per level.
